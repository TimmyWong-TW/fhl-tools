# 信望愛聖經 AI 工具（FHL Bible Tools, fhl-tools）

[English](README.md)

把信望愛站聖經 API（https://bible.fhl.net）包裝成給 AI 代理使用的 MCP 與 UTCP 工具：驗證與轉換參數、一次呼叫多個 PHP 端點、用 cursor 分頁，並為每筆結果附上來源與授權說明。另外也提供信望愛站原始 PHP API 的 OpenAPI 文件，附上實測發現的所有注意事項。

> 注意：信望愛站上部分聖經譯本與資料僅授權給信望愛站使用，請查閱 https://www.fhl.net/main/fhl/fhl8.html 。詳見[授權](#授權)。

## 路由（Cloudflare Worker）

| 路由 | 用途 |
| --- | --- |
| `GET /` | 智慧工具的說明頁 |
| `POST /mcp` | MCP 伺服器（Streamable HTTP、無狀態、JSON 回應） |
| `GET /utcp` | 同一組工具的 UTCP 1.0 manual |
| `GET /tool/<name>?…` | 以 HTTP GET 呼叫單一工具（UTCP 使用；可被邊緣快取）。陣列以逗號分隔；參數錯誤回 `400`，不能提供的內容回 `401` |
| `GET /openapi` | **信望愛站 PHP API 本身**的 Scalar 互動說明；「Try it」直接呼叫 `bible.fhl.net`（原站支援 CORS） |
| `GET /openapi.json` | 忠實描述 PHP API 的 OpenAPI 3.1：原始參數名稱與大小寫、數字代碼、`bid` 對應和合本書名、譯本名稱、注意事項、`curl`／`fetch` 範例、共用 `components/parameters` 與 `allOf` 回應結構 |
| `GET /spec.json` | 產生 OpenAPI 用的 spec |
| `GET /index.json` | 以上路由的機器可讀清單 |

本服務不代管也不轉送 PHP API；OpenAPI 直接指向 `https://bible.fhl.net`。

## 連接 AI 用戶端

託管版 MCP 網址為 `https://fhl-tools.ai4.tw/mcp`。本機版為 `node /path/to/fhl-tools/dist/stdio.mjs`（見[本機版](#本機版全部內容)）。各用戶端的選單名稱常會改變，以下路徑僅供參考。

**Claude Code（命令列）**

```sh
claude mcp add --transport http fhl https://fhl-tools.ai4.tw/mcp     # 託管版
claude mcp add fhl -- node /path/to/fhl-tools/dist/stdio.mjs       # 本機版（全部內容）
```

**Claude（claude.ai、Claude Desktop）**：在「設定 → 連接器 → 新增自訂連接器」輸入託管版網址。Claude Desktop 要用本機版，請在 `claude_desktop_config.json` 加入：

```json
{ "mcpServers": { "fhl": { "command": "node", "args": ["/path/to/fhl-tools/dist/stdio.mjs"] } } }
```

**ChatGPT**：開啟 **Plugins → Add → Add custom MCP server**，填入託管版網址，不需驗證。較舊的版本則是在「設定 → Apps & Connectors」開啟**開發者模式**後新增。ChatGPT 只能連線遠端 HTTPS 伺服器，無法使用本機版。

**VS Code（GitHub Copilot）**：在 `.vscode/mcp.json` 加入：

```json
{ "servers": {
    "fhl": { "type": "http", "url": "https://fhl-tools.ai4.tw/mcp" },
    "fhl-local": { "type": "stdio", "command": "node", "args": ["/path/to/fhl-tools/dist/stdio.mjs"] } } }
```

**Cursor**：在 `~/.cursor/mcp.json` 加入 `{ "mcpServers": { "fhl": { "url": "https://fhl-tools.ai4.tw/mcp" } } }`

**其他 MCP 用戶端**也都可以使用：用 Streamable HTTP 連 `/mcp`，或透過本機版使用 stdio。**UTCP 用戶端**可讀取 `https://fhl-tools.ai4.tw/utcp` 的 manual。

## 本機版（全部內容）

本機版在你自己的電腦上執行，直接連線信望愛站、不快取，如同你自己瀏覽 bible.fhl.net，因此預設提供**全部**工具與譯本，包括僅授權給信望愛站使用的內容。這些內容請只供個人使用，並註明出處。想套用與託管版相同的限制，可設定 `FHL_RESTRICTED=1`。

```sh
git clone https://github.com/TimmyWong-TW/fhl-tools.git && cd fhl-tools
npm install -g pnpm          # Node 25 起不再內建 Corepack
pnpm install && pnpm build:stdio
```

**在本機開 Scalar**：執行 `pnpm dev`，再開啟 http://localhost:8787/openapi ；「Try it」直接呼叫 `bible.fhl.net`。

## 授權

託管版只提供公有領域、著作權已過期，或採開放授權的內容，並在每筆結果的 `source` 欄位註明授權：
- **譯本**：FHL和合本（GFDL）、KJV、ASV、Darby、ERV、BBE、WEB、BHS 內文、深文理和合本、委辦、神天聖書、新遺詔、呂振中、思高、汕頭客語、巴克禮、馬雅各、越南聖經 1934、俄文主教聖經、日文聖經 1955。
- **其他**：1933 次經、FHL 原文字典（GFDL）、舊約字彙分析（CC BY-NC-SA 4.0，限非商業使用）、Torrey 與 Nave's 英文主題查經，以及三種 FDL 或只需署名的錄音。
- **註釋**：信望愛站註釋（FHL註釋，GFDL）為預設；其他六本註釋在信望愛站確認授權前回 401。
- **地點**：名稱、座標與原文編號（事實資料）；說明文字僅本機版提供。
- **珍本**：提供完整書目；頁面影像只提供版權說明允許自由使用者（GNU FDL，或澳洲國家圖書館「註明出處為NLA後可以自由刊載」），其他頁面標為 `withheld`。
- **僅本機版**：`footnotes`（只有 `tcv`／`cnet` 有註腳，兩者都僅授權給信望愛站）與 `baptist_lexicon`（浸宣字典，「僅授權給信望愛站使用」）。

其餘內容僅授權給信望愛站使用或授權不明：透過 HTTP 呼叫回 `401`，透過 MCP 呼叫則回傳說明原因的工具錯誤；只有本機版提供。分類依據信望愛站著作權宣告（2026-10-25），見 [src/licenses.ts](src/licenses.ts)。

## 建置方式

1. `pnpm snapshot` 把說明頁、書卷表（98 卷，含 USFM 代碼）與譯本清單（86 個）存入 `src/snapshot.ts`。
2. `pnpm probe` 實測每個端點（有節流），寫入 `test/fixtures/findings.json`；結果整理在 [docs/FINDINGS.md](docs/FINDINGS.md)。
3. [src/overrides.ts](src/overrides.ts) 記錄實測確認的事實，每筆都綁定說明頁該段落的雜湊。
4. `pnpm build:spec` 產生納入版控的 `src/spec.generated.json`；任何 override 與說明頁段落不符時建置會**失敗**。
5. Worker 提供智慧工具（[src/tools.ts](src/tools.ts)、[src/normalize.ts](src/normalize.ts)）與產生的 OpenAPI（[src/openapi.ts](src/openapi.ts)）。

每次向上游呼叫都是 GET，並用 `cf.cacheTtl` 快取一天。產生的文件以內容雜湊作為 `ETag`（程式更新後不會讀到舊的快取）。Cloudflare 快取只在自訂網域或路由上有效，`*.workers.dev` 不適用。

## 開發

```sh
pnpm install
pnpm check        # build:spec + 型別檢查 + 測試 + README 工具說明檢查（離線）
pnpm readme       # 重新產生兩份 README 的工具說明
pnpm dev          # 在 :8787 執行 wrangler dev
pnpm build:stdio  # 本機版 -> dist/stdio.mjs
```

信望愛站說明頁更新時：執行 `pnpm snapshot`，再執行 `pnpm probe`，檢查結果後更新 `src/overrides.ts` 與 `docs/FINDINGS.md`，最後執行 `pnpm check`。

## 部署（手動）

請在 [wrangler.jsonc](wrangler.jsonc) 的 `SOURCE_URL` 填入所部署程式碼的公開儲存庫網址；說明頁與 `/index.json` 會連結到它，以符合 AGPL 第 13 條提供原始碼的要求。

**信望愛站自己的網頁可完整存取**：[wrangler.jsonc](wrangler.jsonc) 的 `UNRESTRICTED_ORIGINS` 列出 `https://bible.fhl.net`、`https://www.fhl.net` 及其 `http://` 版本。`Origin` 由瀏覽器設定，其他網站無法假冒；非瀏覽器用戶端雖可偽造，但取得的也只是信望愛站公開 API 本來就提供的內容。

```sh
pnpm run deploy   # 先檢查，再 wrangler deploy
```
