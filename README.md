# FHL Bible Tools (fhl-tools)

MCP and UTCP tools for the 信望愛站 (FHL) Bible API at https://bible.fhl.net, built for AI agents. The tools validate and convert arguments, combine several PHP endpoints into one call, page through results with a cursor, and attribute the source and licence of everything they return. This repo also publishes an OpenAPI description of FHL's own PHP API, including every caveat we found by probing it.

## Routes (Cloudflare Worker)

| Route | What |
| --- | --- |
| `GET /` | Human-friendly documentation of the smart tools |
| `POST /mcp` | MCP server (Streamable HTTP, stateless, JSON responses) with the smart tools |
| `GET /utcp` | UTCP 1.0 manual for the same smart tools |
| `GET /tool/<name>?…` | One smart tool over HTTP GET (what UTCP calls; edge-cacheable). Arrays are comma-separated. Bad input gives `400`; content we may not serve gives `401` |
| `GET /openapi` | Scalar reference for **FHL's PHP API itself**, with "try it" calling `bible.fhl.net` directly (FHL sends CORS headers) |
| `GET /openapi.json` | OpenAPI 3.1 for the PHP API **exactly as it is**: documented parameter names and casing, numeric codes, CUV book names for `bid`, version names, caveats, `curl`/`fetch` samples, shared `components/parameters`, and `allOf` response schemas |
| `GET /spec.json` | The scaffolded spec that OpenAPI is generated from |
| `GET /index.json` | Machine-readable list of the routes above |

We neither host nor proxy the PHP API. OpenAPI points straight at `https://bible.fhl.net`.

## Connect an AI client

The hosted MCP URL is `https://fhl-tools.ai4.tw/mcp`. The local server is `node /path/to/fhl-tools/dist/stdio.mjs` (see [Local server](#local-server-all-content)). Client menus change often, so treat the paths below as a guide.

**Claude Code (CLI)**

```sh
claude mcp add --transport http fhl https://fhl-tools.ai4.tw/mcp     # hosted
claude mcp add fhl -- node /path/to/fhl-tools/dist/stdio.mjs       # local, all content
```

**Claude (claude.ai and Claude Desktop):** go to *Settings → Connectors → Add custom connector*, then enter the hosted URL. For the local server in Claude Desktop, add this to `claude_desktop_config.json`:

```json
{ "mcpServers": { "fhl": { "command": "node", "args": ["/path/to/fhl-tools/dist/stdio.mjs"] } } }
```

**ChatGPT:** open **Plugins → Add → Add custom MCP server**, then enter the hosted URL with no authentication. On older builds, the equivalent is *Settings → Apps & Connectors* with **Developer mode** turned on. ChatGPT only connects to remote HTTPS servers, so the local server isn't an option there.

**VS Code (GitHub Copilot):** add to `.vscode/mcp.json`:

```json
{ "servers": {
    "fhl": { "type": "http", "url": "https://fhl-tools.ai4.tw/mcp" },
    "fhl-local": { "type": "stdio", "command": "node", "args": ["/path/to/fhl-tools/dist/stdio.mjs"] } } }
```

**Cursor:** add to `~/.cursor/mcp.json`: `{ "mcpServers": { "fhl": { "url": "https://fhl-tools.ai4.tw/mcp" } } }`

**Any other MCP client** works too: Streamable HTTP at `/mcp`, or stdio via the local server. **UTCP clients** can read the manual at `https://fhl-tools.ai4.tw/utcp`.

## Local server (all content)

The local server runs on your own machine and fetches FHL live, with no cache, much like you browsing bible.fhl.net. So by default it offers **every** tool and version, including content licensed only to FHL. Keep that content to personal use and cite the source. Set `FHL_RESTRICTED=1` to apply the hosted policy instead.

```sh
git clone https://github.com/TimmyWong-TW/fhl-tools.git && cd fhl-tools
npm install -g pnpm          # Node 25+ no longer bundles Corepack
pnpm install && pnpm build:stdio
```

**Scalar on localhost:** run `pnpm dev`, then open http://localhost:8787/openapi. "Try it" calls `bible.fhl.net` directly.

## Smart tools

Books accept USFM codes (`JHN`, `1MA`), CUV names (`約`, `約翰福音`), English names (`John`) or FHL numbers. Output uses LLM-friendly field names (`book`, `chapter`, `verse`, `text`, `strongs`…), not the PHP API's names. Tool descriptions are in Chinese, the language of the data. The hosted service withholds content per item (see [Licensing](#licensing)).

## Licensing

The hosted service serves only content that is public domain, out of copyright, or under an explicit open licence, and it attributes each item in a `source` field:
- **Versions:** FHL和合本 (GFDL), KJV, ASV, Darby, ERV, BBE, WEB, BHS text, 深文理和合本, 委辦, 神天聖書, 新遺詔, 呂振中, 思高, 汕頭客語, 巴克禮, 馬雅各, Vietnamese 1934, Russian Synodal and Japanese 1955.
- **Other content:** the 1933 apocrypha, the FHL dictionary (GFDL), OT parsing (CC BY-NC-SA 4.0, non-commercial), Torrey and Nave's in English, and three FDL / attribution-only audio recordings.
- **Commentary:** 信望愛站註釋 (FHL commentary, GFDL), which is the default. The other six commentaries return 401 until FHL confirms their licences.
- **Places:** names, coordinates and Strong's numbers (facts). The descriptive text is local only.
- **Rare books:** the full catalogue, plus page images only for books whose copyright line grants free use (GNU FDL, or the National Library of Australia's "註明出處為NLA後可以自由刊載"). Other pages are reported as `withheld`.
- **Local only:** `footnotes` (only `tcv`/`cnet` have footnotes, and both are licensed to FHL) and `baptist_lexicon` (浸宣 dictionaries, "僅授權給信望愛站使用").

Everything else is licensed only to FHL or has an unclear licence. Over HTTP it answers `401`, and over MCP it returns a tool error explaining why. It is served only by the local stdio server. The classification is in [src/licenses.ts](src/licenses.ts) and is based on FHL's copyright page (2026-10-25).

## How it is built

1. `pnpm snapshot` saves the docs page, the book table (98 books with USFM codes) and the version list (86) into `src/snapshot.ts`.
2. `pnpm probe` sweeps every endpoint live (throttled) and writes `test/fixtures/findings.json`. The results are summarized in [docs/FINDINGS.md](docs/FINDINGS.md).
3. [src/overrides.ts](src/overrides.ts) holds the confirmed facts, each pinned to its docs section's hash.
4. `pnpm build:spec` generates the checked-in `src/spec.generated.json`. The build **fails** if any override no longer matches its docs section.
5. The Worker serves the smart tools ([src/tools.ts](src/tools.ts), [src/normalize.ts](src/normalize.ts)) and the generated OpenAPI ([src/openapi.ts](src/openapi.ts)).

Every upstream call is a GET with `cf.cacheTtl` of 1 day. Generated documents get an `ETag` hashed from their content (so code changes are never masked by a stale copy). Cloudflare's caching only applies when the Worker runs on a custom domain or route, not on `*.workers.dev`.

## Deploy (manual)

Set `SOURCE_URL` in [wrangler.jsonc](wrangler.jsonc) to the public repository of the code you deploy. The docs page and `/index.json` link to it, which is how AGPL §13's source offer is met.
